# Pheezo Logistics Enterprise (P.L.E.)

**Logistics, simplified.**

A modern, responsive business website developed for Pheezo Logistics Enterprise to present its brand, services and contact options.

## Live Website

[Visit Pheezo Logistics](https://pheezologistics.netlify.app/)

## Project Overview

This project is a business website designed with a clean, modern corporate appearance. It provides visitors with information about the business, its services and ways to make enquiries or request a quote.

## Features

- Responsive design for desktop and mobile devices
- Navigation menu with mobile support
- About Us section
- Services section
- Why Choose Us section
- Contact form
- Request a Quote form
- Netlify Forms integration

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Netlify
